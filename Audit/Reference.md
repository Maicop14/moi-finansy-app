## Граница доступа

Плагин содержит несколько десятков инструкций для агента. Установка всего плагина и его автоматические обновления расширяют объём сторонних инструкций, к которым агент может обращаться в будущих сеансах. Скрипт разработчика `scripts/link-skills.sh` записывает символьные ссылки в пользовательские каталоги навыков и может удалить существующий одноимённый каталог перед заменой. [Манифест](https://github.com/mattpocock/skills/blob/5863806dd4e15c63174bee4e7515a4256792ecfa/.claude-plugin/plugin.json) · [Скрипт](https://github.com/mattpocock/skills/blob/5863806dd4e15c63174bee4e7515a4256792ecfa/scripts/link-skills.sh)

Материалы прочитаны из отдельной локальной копии Git без рабочего дерева. Выполнение сторонних скриптов и установка плагина для этой проверки не потребовались. В конфигурации сборки и исходниках приложения зависимость от этого репозитория отсутствует. Ни видеозапись, ни финансовые данные для установления источника из компьютера не передавались. Выводы о внешнем проекте ограничены перечисленными файлами указанной ревизии.
